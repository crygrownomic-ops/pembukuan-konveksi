⚠️ Browser Anda saat ini (Safari/Firefox/Mobile) tidak mendukung File System Access API. Untuk menggunakan fitur tautkan folder Drive C/D lokal ini, harap gunakan browser Google Chrome atau Microsoft Edge di Komputer/Desktop.

📘 Panduan Penggunaan Aplikasi (v1.6.0)

1. Sinkronisasi Cloud Real-Time: Terhubung langsung ke Firebase Cloud Database. Setiap transaksi baru yang diinput atau dihapus akan otomatis terbarui di seluruh perangkat tanpa perlu di-refresh.

2. Rincian Biaya & Laba: Perhitungan otomatis meliputi omzet, ongkos tukang (potong, jahit, press, kancing, finishing), sisa bayar, dan estimasi laba kotor.

3. Mode Offline Fallback: Jika koneksi cloud terputus, aplikasi akan mengalihkan penyimpanan sementara ke LocalStorage.
